# API y MCP — Animación para comerciales

Animación interactiva basada en RESULTADO.md. Incluye dos recorridos simultáneos, tres ejemplos, pausa, reinicio, velocidad ajustable y navegación por pasos.

Abrir `index.html` en cualquier navegador moderno. No requiere instalación ni conexión. Las cifras de los ejemplos son ficticias.

## Publicar en GitHub Pages

Repositorio previsto: `lucaba/api-vs-mcp` (público).

1. Subir `index.html` y este README a la raíz del repositorio.
2. En Settings → Pages, elegir Deploy from a branch.
3. Seleccionar main y / (root), y guardar.
4. Cuando termine el despliegue, compartir https://lucaba.github.io/api-vs-mcp/.

La dirección anterior es la prevista; solo funcionará tras crear el repositorio y activar Pages.
